# Sprint 06 pull request reading

Threadline can open a downloaded pull request in independent conversation and file views. Each tab keeps its comparison, file and scroll position as the reader changes between the PR body and a verified issue. Clean Linux tests and native Windows application tests passed. The Windows 11 native run passed the two-tab delayed-response scenario and reopened the verified issue in its original PR.
